---
RPAM — Reproducible Pallet Alias Manager

TUI-менеджер команд, workflow и пользовательских действий для Linux/NixOS, вдохновлённый:

Yazi

LazyGit

command palette из IDE



---

Главная цель

Создать систему управления командами и workflow без зависимости от:

.bashrc

.zshrc

.fish

shell-specific aliases



---

Основная идея

Вместо хаоса alias-файлов пользователь получает структурированный интерфейс:

Categories -> Commands -> Actions

Пример:

nix/
waydroid/
gaming/
mtp/
backup/
docker/


---

Концепт интерфейса

Интерфейс работает как файловый менеджер.

Левая колонка

Категории / группы.

Центральная колонка

Команды внутри категории.

Правая колонка

Превью:

полная команда

описание

теги

нужен ли sudo

история запусков

backup info

---

Структура хранения

Вместо одного огромного shell config:

~/.config/rpam/

Например:

~/.config/rpam/nix/rebuild.toml
~/.config/rpam/nix/update.toml
~/.config/rpam/waydroid/start.toml


---

Пользователь:
